## 1. 关键交互决策

1. **三栏而不是右侧栏**：群组同时要「选群、看时间线、追踪成员与任务」，三件事必须同屏；右侧栏只作为 v1.1 的速览入口。
2. **「发送一轮」而不是「发送」**：确认这是会议制——Owner 一发消息就唤醒被点名/广播的成员；发送前显示会唤醒几个会话（成本可见）。
3. **投递状态可见**：Owner 消息卡带「已投递 4/4 · 1 运行中 · 2 已回复」；失败/超时会以系统事件出现（本稿未画全部状态，见提案 §7.8）。
4. **等待中的成员必须可跳转**：成员在会话里长时间未结束（可能等待审批/提问）时，群组**不代答**，只给「去处理」→ 打开成员会话。
5. **任务板常驻右栏**：任务与时间线互相引用；完成需 Owner 确认或验收证据，未完成不自动改验收项。
6. **群组边界固定展示**：右下角常驻「群组不改变流水线 / 审批闸门」，避免与流水线、验收台混淆。
7. **群组列表带计数**：进行中/待你处理/暂停/归档在列表即可见；「2 待你处理」与上方群组视图角标联动。

## 2. 尺寸与样式

- 间距：4/8px 体系；页面边距 24px；栏间距 16px；卡片圆角 10px，内层控件 8px。
- 颜色：主色 `#2563eb`；文字 `#0f1115`；次级 `#61666b`；弱化 `#8a9099`；状态绿 `#16a34a` / 琥珀 `#d97706` / 灰 `#8a9099`；边框 `#e3e6ea`。
- 控件：桌面按钮 32–34px 高；成员行 56px；消息卡内边距 16px；成员/任务列表项可点击区域整行。
- 移动端（未画入本稿）：<900px 三栏变单栏切换，composer 固定底部，触控目标 ≥44×44，成员/任务以抽屉展示。

## 4. 无障碍与校验

- SVG 带 `<title>` / `<desc>`；状态不只靠颜色（均有文字标签）；时间线新消息 `aria-live="polite"`；`@` 选择与发送支持键盘。
- 结构校验：XML 良构。**说明**：当前构建机没有 CJK 字体，未做位图渲染校验；请直接用浏览器打开 SVG 查看（字体栈 PingFang / Microsoft YaHei / Noto Sans SC）。
